Glossary

Key terms and concepts used across the apps on this site.

How This Project Works

Repository (Repo)
A folder that contains all the project's files along with the full history of every change ever made. This site lives in a single Git repository hosted on GitHub.
Git
A version-control system that tracks changes to files over time. It lets multiple people work on the same codebase without overwriting each other's work, and makes it easy to undo mistakes.
Commit
A snapshot of the project at a specific point in time. Each commit has a message describing what changed and why. The full chain of commits forms the project's history.
Branch
A parallel line of development. You create a branch to work on a feature or fix without affecting the main codebase. The default branch is usually called main.
Pull Request (PR)
A proposal to merge changes from one branch into another. It shows exactly what changed and lets others review, comment, and approve before the code is merged. The main way contributions are reviewed on GitHub.
Merge
The act of combining changes from one branch into another. After a pull request is approved, it gets merged — incorporating all its commits into the target branch.
GitHub
A platform for hosting Git repositories online. It adds collaboration features like pull requests, issues, and actions on top of Git. This project is hosted on GitHub.
GitHub Actions
An automation system built into GitHub. This project uses a GitHub Action that automatically builds and deploys the site every time code is pushed to the main branch.
CI/CD (Continuous Integration / Continuous Deployment)
The practice of automatically building, testing, and deploying code whenever changes are made. The deploy workflow in this project is a CI/CD pipeline — push code, and the site updates itself.
Deploy
Publishing a new version of the site so it's live on the internet. Here, deploying means building each app and uploading the result to GitHub Pages.
Issue
A tracked task, bug report, or feature request on GitHub. Issues are used to discuss what needs to be done before any code is written.
Build
The process of transforming source code (TypeScript, JSX, CSS) into optimized files a browser can run. The React apps go through a build step; the static apps do not.

General Tech

GitHub Pages
The free hosting service from GitHub that serves this site. Every push to the main branch triggers a deploy that builds and publishes all apps.
Vite
A fast build tool used by the React-based apps (Lineup Guesser, Bracket City, Hangman). It bundles source code into optimized files for the browser.
React
A JavaScript UI library. Most apps on this site are built with React and TypeScript, using components and hooks to manage game state.
TypeScript
A typed superset of JavaScript. Adds type annotations to catch errors before the code runs. Used by the React-based apps.
Tailwind CSS
A utility-first CSS framework that lets you style elements with short class names (e.g. bg-blue-500) directly in HTML. Used by some of the React apps.
Static App
An app built with plain HTML, CSS, and JavaScript — no build step required. The Calendar Puzzle and Pokémon games are static apps.

Game Concepts

Hint all games
An optional clue you can request during a game. Hints make the puzzle easier but usually cost you points or reduce your score.
Streak
A count of consecutive correct answers. Used in games like Who's That Pokémon to track how many you get right in a row.
Daily Puzzle
A puzzle that changes once per day so every player gets the same challenge. Used by the Calendar Puzzle and Bracket City.
Fuzzy Matching
A forgiving way to check answers. Small typos and missing accents are tolerated using techniques like Levenshtein distance. Used in Lineup Guesser.
Levenshtein Distance
A measure of how different two strings are, counting the minimum number of single-character edits needed to turn one into the other. Powers the fuzzy matching in Lineup Guesser.

App-Specific Terms

Formation Lineup Guesser
The tactical arrangement of players on the pitch (e.g. 4-3-3, 3-5-2). Each match uses a real formation from the Premier League.
Bracket / Nested Bracket Bracket City
A clue wrapped in square brackets. Brackets can contain other brackets, and inner brackets must be solved before the outer one becomes solvable.
Hidden Word Hangman
The single word in a news headline that you need to guess letter by letter. The rest of the headline is shown in gray as context.
Silhouette Pokémon
A blacked-out outline of a Pokémon. Your job is to identify which Pokémon it is from the shape alone.
Pentomino Pieces Calendar Puzzle
The shaped tiles you place on the board. Inspired by the DragonFjord A-Puzzle-A-Day, you must arrange them to leave only today's date uncovered.
